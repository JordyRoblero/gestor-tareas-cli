# Gestor de Tareas CLI

## Descripción
Aplicación desarrollada en Python que permite
administrar tareas desde la consola.

## Requisitos previos
- Python 3 instalado.
- Git instalado.

## Funcionalidades
- Agregar tareas.
- Listar tareas.
- Completar tareas.
- Eliminar tareas.

## Ejecución

Ejecutar el siguiente comando:

python app.py
